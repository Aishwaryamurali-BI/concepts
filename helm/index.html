How this runs

1. Visit logs and dealer program sales load every Monday.
2. Each dealer is compared with similar dealers that had no visit.
3. AI drafts each recap from the visit notes; every number cites its source row.
4. The consultant approves or edits before anything is sent.
5. A weekly test set checks the drafts for wrong numbers before each release.
All dealers, consultants and figures on this page are invented for illustration. Built to show how field-visit data could be turned into program proof for an OEM partner. Concept and build by Aishwarya Murali, aishwaryamurali.com.
